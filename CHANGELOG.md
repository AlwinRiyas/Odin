# Changelog

All notable changes to this project are documented here.

## [Unreleased]

- Future changes will follow semantic versioning and the stable release policy.

## [1.0.0]

- Declared the public CLI and package contract stable.
- Finalized the modular scan engine and configurable profiles.
- Finalized passive security checks and explicitly controlled active checks.
- Finalized risk scoring and severity normalization.
- Finalized terminal, JSON, HTML, and SARIF reporting.
- Finalized project configuration and validation.
- Finalized CI quality gates and package distribution validation.
- Added stable release documentation and maintenance guidance.

## [0.9.0]

- Added validated project configuration.
- Added configurable scan profiles and output settings.
- Added CI quality matrix across supported Python versions.
- Added package build and distribution validation.
- Added TestPyPI and PyPI trusted-publishing workflows.
- Added release candidate contract tests.
- Added release documentation and readiness checklist.

## [0.8.0]

- Added terminal, JSON, HTML, and SARIF reporting.
- Added report serialization tests.

## [0.7.0]

- Added risk scoring and confidence weighting.
- Added risk-aware CLI failure thresholds.

## [0.6.0]

- Added explicit active-scan policy controls.
- Added bounded reflected-input and database-error indicator checks.

## [0.5.0]

- Expanded passive security scanners.
- Added HTTP method and information-disclosure checks.
